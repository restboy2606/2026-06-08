### 1-2. GitHub 인증 — 멀티계정 함정 재발

이 PC에도 `iggn-official` 계정이 Windows Credential Manager에 캐시되어 있었다.
`gh auth login --with-token`을 pipe로 시도했지만 `GH_TOKEN` 환경변수가 설정된 상태에서는 토큰 저장이 블록됨.

```
The value of the GH_TOKEN environment variable is being used for authentication.
To have GitHub CLI store credentials instead, first clear the value from the environment.
```

**최종 해결:** Bash(WSL 경유)에서 GH_TOKEN 없이 pipe로 주입 → keyring 저장 성공.
그러나 이후 `git push`는 여전히 Windows Credential Manager를 타서 403 발생.

**근본 해결:** 각 push 전 remote URL에 토큰을 직접 embed하는 방식으로 처리.

```powershell
git remote set-url origin "https://restboy2606:<TOKEN>@github.com/restboy2606/2026-06-08.git"
git push origin main
git remote set-url origin "https://github.com/restboy2606/2026-06-08.git"  # 바로 원복
```

> ⚠️ 토큰은 `.env`에 있고 커밋되지 않음. push 후 반드시 URL 원복할 것.

## 4. 기술 메모

### 4-1. CSS 게임 화면 목업

실제 스크린샷 없이 CSS만으로 게임 UI처럼 보이는 목업 제작:
- 배경: gradient (게임 테마별 색상)
- 픽셀 그리드 오버레이: `background-image: linear-gradient(...)` 24px 격자
- HP/MP 바: flex + fill div
- 제목: Mona 폰트로 상단 바에 표시

### 4-2. 무한 스크롤 마키 (Gallery)

```css
@keyframes marqueeLeft  { 0% { transform: translateX(0); } 100% { transform: translateX(-50%); } }
@keyframes marqueeRight { 0% { transform: translateX(-50%); } 100% { transform: translateX(0); } }
```

아이템을 2배로 복사(`[...items, ...items]`)해서 이음새 없는 무한 스크롤.
hover 시 `animation-play-state: paused`.

### 4-3. Navbar 글래스모피즘

```jsx
const [scrolled, setScrolled] = useState(false)
useEffect(() => {
  const onScroll = () => setScrolled(window.scrollY > 50)
  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])
```

```css
.nav--scrolled {
  background: rgba(8, 8, 8, 0.85);
  backdrop-filter: blur(20px);
  border-bottom: 1px solid rgba(255, 255, 255, 0.07);
}
```

### 4-4. Mona 폰트 사용법

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/MonadABXY/mona-font/web/mona.css" />
```

```css
font-family: 'Mona12', 'Mona10', monospace;
```

픽셀 비트맵 폰트라 큰 사이즈에서 의도적으로 픽셀 느낌이 남. 게임사 브랜드에 적합.
참고 사이트: https://monadabxy.com/fonts/mona/
